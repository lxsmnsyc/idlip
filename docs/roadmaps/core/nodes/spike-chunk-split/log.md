# Log: spike-chunk-split

- Read brumate `vite.ts`. Client modules are `<file>?brumate-client` in dev. The client build writes `.brumate/hints.json` in `writeBundle` and keeps it in a closure (`builtHints`) for a server build in the same process. The server build loads it through a virtual module. HMR invalidates `.brm` and `\0virtual:brumate*` modules and sends `full-reload`.
- Prototype in `proto/` with its own `node_modules` (`pnpm install --ignore-workspace`), Vite 8.3.4, Rolldown 1.2.19, oxc-parser 0.154.0, Node 26.12.1.
- First build failed: `Failed to detect the lang of .../todo.idlip.tsx?idlip-binding=save.state`. Vite takes the loader from the end of the whole id, so `.state`, `.done` and `.text` read as extensions. Fixed by ending every chunk id with `&lang.tsx`. `moduleType: 'tsx'` in the `load` result did not help.
- First dev run failed: the transform output still had types. A normal plugin's `transform` runs after Vite's TypeScript transform in dev, but before it in build. Fixed with `enforce: 'pre'`.
- Build (`npx vite build --app`): 9 chunks for the todo fixture plus a 292 B `runtime` chunk shared with the loader entry. Rolldown merged no chunk, the smallest is 376 B. `IDLIP_CHUNK_OPT=off` (`experimental.chunkOptimization: false`) gave the same files and hashes.
- `IDLIP_HELPERS=import`: a 182 B shared `todo.idlip.tsx_idlip-helpers_lang` chunk appears and every chunk imports it, so a click costs one more request.
- `IDLIP_HELPERS=import IDLIP_INLINE_COMMON=1024` (`experimentalInlineCommonChunks`): helpers inlined, but every chunk grows to 1.3-2.0 kB with `__share` wrappers. A 1.2 kB `rolldown-runtime` chunk appears, and `runtime.ts` is copied into each chunk. Rejected.
- Dev (`node dev.ts`): server render reads `virtual:idlip/manifest` with `/src/todo.idlip.tsx?idlip-handler=toggle&lang.tsx` style URLs. Each URL transforms in the client environment. Editing `toggle` only: `hotUpdate` gets all 9 chunk modules of the file, and the diff shows only `handlers:toggle` changed. Editing `countLeft`: every chunk changed, since the stub copies all helpers into all chunks.
- Lint: the type-aware rules fail on the prototype (no tsconfig, own node_modules). Added a file-level `oxlint-disable` with a reason to each prototype file. Root `pnpm lint` already fails on batch/core because of `docs/roadmaps/core/debates/subscriptions/evidence/*.tsx`, not this node.
